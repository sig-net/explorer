DEVIATIONS
- The step says stop() "stops accepting and closes its open connections" before the loops abort. Built: the server stops accepting and Node closes idle connections at once, a request already in flight is answered while the loops are awaited, and the remaining connections are closed after that wait, before the pool is destroyed. Reason: the test title asks for 503 from /readyz after stop(), which HTTP can show only on a connection that survives the start of stop(). The test sends the start of a request before stop() and its end after.
- stop() also waits (within the same 8 s) for a migration in flight, so that the pool is not destroyed under it.
- The log entry of a failed migration carries `network`. An unknown wipe-network argument is quoted with JSON.stringify in the error.
