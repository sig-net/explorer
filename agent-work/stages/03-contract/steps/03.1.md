## Goal

`@sig-net/explorer-api` is the whole HTTP contract (D20): zod wire schemas, the `ExplorerService` interface, a fetch client that implements it, a Hono routes adaptor that serves it, and an in-memory service with a seed that the UI and the server shell are built against.

- `packages/lib/src/midnight/signet-events.ts` (`StoredSignetMiscEvent`, `decodeSignetContractEvent`), `sign-bidirectional-lifecycle.ts:15-92` and `sign-bidirectional-lifecycle.fixture.ts` (through `@sig-net/explorer-lib/testing`).
- `packages/ui/src/lib/midnight/sign-bidirectional-transaction-inspection.ts:21-39` (`ContractCallNode`, the inspection type) and `:172-178` (how a cell becomes the record, with the `txParamType` check). The api package cannot import from the UI: define these types here.

- `agent-work/probes/request-cell-wire.mjs` and `request-cell.wire.json`, and "The wire" of the backend pack.

## Work

1. Ground. `tsconfig.json`: add `"DOM"` to `lib`. `package.json`: `exports` becomes `"."` and `"./testing": "./src/testing.ts"`. Add no dependency: `yarn.lock` is outside your scope. Type a cell as `Parameters<typeof decodeEvmType2SignBidirectionalEvent>[0]`. Files: `src/wire.ts`, `service.ts`, `client.ts`, `routes.ts`, `testing.ts`, all but the last exported from `index.ts`.
2. `ExplorerService`, every method async:
   - `networks()`: for each served network, `network`, `config` (`signerContractAddress`, `responderContractAddress`, `startBlock`, `sourceUrl` with no query string) and `sync` (`state`: `starting`, `syncing`, `synced` or `stopped`, then `processedBlock`, `processedBlockTime`, `tipBlock`, `lastSuccessAt`, `error`, each null until known).
   - `lifecycles(network, { search?, excludeCallers?, before?, limit? })`: `lifecycles` newest first (by first event id, descending), `nextBefore` (the first event id of the page's last lifecycle, null at the end), `matchingRequests`, `totalRequests`, `totalEvents` (every stored event). `limit` defaults to 50, at most 200. `search` is a fragment of a request id or caller, case-insensitive, optional `0x`. `excludeCallers` never hides a lifecycle that names no caller.
   - `lifecycle(network, requestId)`: one lifecycle, or null. `callers(network)`: the distinct callers.
   An unknown network throws `ExplorerApiError` (a class with `code`), never an empty answer.
3. The domain lifecycle: lib's `SignBidirectionalLifecycle` plus `firstEventId`, where each sign bidirectional event also carries `inspection`: `{ callChains, request }` (`request` null when the transaction wrote none) or `{ failed: reason }`.
4. The wire, as zod schemas. A lifecycle is `{ requestId, firstEventId, events }`, the events in emission order. An event is its stored source: `id`, `name`, `payload` (hex), `transactionHash`, `blockHeight`, `blockHash`, `blockTime`, `roles`, and for a sign bidirectional event `inspection`: `{ callChains, requestCell }` or `{ failed }`. Export `lifecycleWireSchema`, `lifecycleToWire` and `lifecycleFromWire`. The last rebuilds each event with lib's `decodeSignetContractEvent` and groups with `aggregateSignBidirectionalLifecycles`, and decodes `requestCell` as `:172-178` does: a cell that throws there becomes `{ failed }`.
5. Routes under `/v1`: `GET /networks`, `/networks/:network/lifecycles`, `/networks/:network/lifecycles/:requestId`, `/networks/:network/callers`. Errors are `{ error: { code, message } }`: `unknown_network` and `not_found` (404), `invalid_request` (400), `unavailable` (503). `explorerApiRoutes(service)` returns a Hono app with no CORS and no health route: the backend owns those.
6. `createExplorerApiClient({ baseUrl, fetch? })` returns an `ExplorerService`. It validates every response with the schemas and throws `ExplorerApiError` for an error body or a body that does not validate (`invalid_response`). `lifecycle` answers null for `not_found`.
7. `createInMemoryExplorerService(seed)` in `testing.ts`: it holds stored events and inspections per network and answers by the same rules. Export `explorerSeed` with at least: a complete lifecycle whose request cell is the probe's, a response with no request, a request notified twice, a failed inspection, a lifecycle with no caller.
8. Tests, with these titles:
   - `round trips every event kind through the wire`
   - `round trips the request record through the wire` (the decoded record hashes to the request id the backend pack names)
   - `a request cell that does not decode becomes a failed inspection`
   - `client and routes agree over the in-memory service` (every method, the client's `fetch` being the routes' `app.request`)
   - `pages newest first without repeating or skipping a lifecycle`
   - `searches by a fragment of a request id or a caller`
   - `excludes callers and keeps a lifecycle that names none`
   - `answers 404 for an unknown network and an unknown request`
   - `answers 400 for an invalid query`
   - `the client rejects a body that does not validate`
   - `the source url carries no query string`
   - `the seed holds every case the step lists`
