## Goal

`packages/lib` exists as `@explorer/lib` and holds the three things the design gives it: the
Midnight network set, the value schemas, and Signet event decoding. The UI imports them from
there and no longer defines them. The package runs in the browser and in Node.

## Read first

- `packages/ui/src/lib/midnight/network.ts:1-20,340-375` (the network set and its guards)
- `packages/ui/src/lib/midnight/contract-address.ts`, `signet-events.ts` and their tests
- `packages/ui/src/lib/midnight/network.ts:100-110`: `parseMpcRootPublicKey`
- The repository's `AGENTS.md`, "Boundaries and ownership": the census rule you are applying.

## Work

1. Census first, and put it in your report: for each name you are about to move, every file
   that imports it today (`git grep`), and the runtime of each future consumer: `ui` (browser),
   `api` (browser and Node), `backend` (Node). Move a name ONLY when `api` or `backend` will
   import it by the design. Everything else stays in the UI. If the census surprises you, stop
   and report BLOCKED.
2. Make the package as the `layout` pack says, depending on `@sig-net/midnight` (the UI's exact
   version) and `zod`. Add it to the root references and to `packages/ui`'s dependencies as
   `workspace:*`.
3. Move, with their tests, each into a file named for what it holds:
   - `midnight-networks.ts`: `MIDNIGHT_NETWORKS`, `isMidnightNetwork`, and a zod
     `midnightNetworkSchema` over the SDK's enum.
   - `contract-address.ts`: `parseContractAddressHex`, `normaliseContractAddressHex`,
     `parseContractAddressesHex`.
   - `value-schemas.ts`: zod schemas for the values the API will carry, each producing the
     canonical form: a contract address (64 lowercase hex), a request id (through the SDK's
     `parseRequestIdHex`), a transaction or block hash (64 lowercase hex), bytes as hex (even
     length, lowercase, no `0x`), a block height (a non-negative safe integer), an MPC root
     public key (through `normaliseSecp256k1PublicKey`), an ISO 8601 UTC time.
   - `signet-events.ts`: `SignetContractRole`, `SignetContractEvent` and
     `decodeSignetContractEvent`. Make the event type generic over its source
     (`TSource extends SignetMiscEvent`), because the backend's source and the API's source are
     not the indexer's `IndexedSignetMiscEvent`. The UI keeps using it with the indexed source.
4. The UI's `network.ts` keeps everything about configuration and environment. It imports the
   moved names. The mover pays: `git grep` each moved name and each moved path over the whole
   repository, and update every import, test and document.
5. Check the package's reach: no `node:` import, no `process`, no `import.meta.env`, no DOM
   type, no React. Its tests run under vitest's Node environment.
6. `yarn install`, commit the lockfile, then `yarn lint`, `yarn build`, `yarn check`. Count the
   `.wasm` files of the UI build. Commit.

## Done when

`checks/03.1.sh` proves the package exists with its four files, the UI no longer defines the
moved functions, the package reaches nothing outside both runtimes, Node imports it with no
build, the UI build has its two WebAssembly files, and all checks pass with no test lost. It
cannot prove the census was honest: the orchestrator reads it in the report against `git grep`.
