The store holds every caller of a request, as the API, the in-memory service and the UI already use them (D36), and a page of lifecycles carries the event count of the matching requests (D37).

## Work

Every dependency is installed: change no manifest. No database is deployed anywhere, so the schema changes are made in `0001_network_tables.sql` itself and no second migration file is added. Start a database for your own runs with `with_postgres` (backend pack).

1. A table `request_callers (request_id, caller)`: primary key on both, `request_id` references `requests`, `caller` lower case hex `text` with the CHECK the other hex columns have, a trigram index on `caller`, and a plain index that serves "the distinct callers of the network" and "the requests of one caller". `requests.caller` and its index go: the fact has one home.
2. `schema.ts`: the Kysely interface of the new table, and `requests` without `caller`. If the `lifecycle` view names the column, it follows.
3. `LifecyclePage` gains `matchingEvents`: the events of the requests that match the search and the exclusion, over all pages, as `matchingRequests` counts the requests. The wire schema, the routes, the client and the in-memory service carry it. In the store it is the sum of the count columns of `requests`: say so in the doc of the field only if a reader of the type needs it.
4. Tests, with these titles:
   - backend: `the store keeps every caller of a request` (one request, two callers, both found by a fragment search of `request_callers` and both listed as distinct callers).
   - backend: `a caller search reads no table in full` (20,000 requests with callers by `generate_series`, `ANALYZE`, `EXPLAIN` the newest 50 requests that have a caller matching a fragment, and the same with one caller excluded: no `Seq Scan` on `requests`, `events` or `request_callers`. A timeout of its own).
   - api: `a page counts the events of the matching requests` (on `explorerSeed`: with no filter it equals `totalEvents` less the events that belong to no request if the seed has such, with a search and with an exclusion it is the sum over the matching lifecycles, and it does not change with `limit` or `before`).
   Plant a fault for each and see it fail, restoring from a copy.
5. Every test that exists still passes, the eight titles of 03.2 among them.
