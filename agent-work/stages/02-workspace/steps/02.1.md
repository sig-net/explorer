## Goal

The repository root is a yarn workspaces root, and the app lives in `packages/ui` as `@sig-net/explorer-ui`, unchanged in behaviour. `yarn check` and `yarn build` at the root still do what they did.

## Read first

- `package.json`, `vite.config.ts`, `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`, `components.json`
- `.oxlintrc.json`, `.oxfmtrc.json`, `.dockerignore`, `Dockerfile`, `docker/`
- `README.md` and `AGENTS.md`: both name paths under `src/`.

## Work

1. `git mv` into `packages/ui/`: `src`, `public`, `index.html`, `vite.config.ts`, `components.json`, the three `tsconfig*.json`, `Dockerfile` and `docker/`. Nothing of the app stays at the root.
2. `packages/ui/package.json`: name `@sig-net/explorer-ui`, private, with the app's dependencies and its `dev`, `build`, `preview`, `typecheck` and `test` scripts.
3. Root `package.json`: private, `"workspaces": ["packages/*"]`, and it keeps `packageManager`, `engines`, `resolutions` and the lint and format tools. Its scripts: `typecheck`, `test` and `build` run every workspace that has the script (`yarn workspaces foreach -A --topological run <script>`), `lint`, `format` and `format:check` run oxlint and oxfmt once over the whole repository, `dev` runs the UI's, and `check` stays typecheck, lint, format check, test in that order.
4. Point `.oxlintrc.json` (its `overrides` globs, its Tailwind `entryPoint`, its `ignorePatterns`) and `.oxfmtrc.json` at the new paths. Keep `agent-work` ignored in both. `packages/ui/dist` and `packages/ui/src/routeTree.gen.ts` stay ignored.
5. `packages/ui/Dockerfile` builds from the repository root as its context: it copies the root manifests and every workspace's `package.json` before `yarn install --immutable`, runs `yarn workspace @sig-net/explorer-ui build`, and serves `packages/ui/dist`. Update `.dockerignore` for the new paths.
6. The mover pays: search the whole repository for every path that moved (`src/`, `public/`, `docker/`, `dist`, `Dockerfile`, `vite.config.ts`, `components.json`) and update each hit in `README.md`, `AGENTS.md`, `.claude/`, `.vscode/`, `.gitignore`. Do not edit `.github/workflows/**`: list in your report each line there that names a moved path, with the value it needs.
7. `yarn install`, then run the exit check.

## Done when

`checks/02.1.sh` proves the root is a workspace root with no `src`, the repository checks and the build pass, the build emits the same set of WebAssembly files as before, a build under `/explorer/` succeeds, and the UI image builds. It cannot prove the README still reads true: the final review reads it.
