## Goal

The test "the button excludes the typed address, and marks the box when it is not one" passes on every run of the full UI suite, because the cause of its timeout is found and removed.

## Read first

- `packages/ui/src/components/midnight/excluded-callers-filter.test.tsx`, around line 65: the assertion `toHaveAttribute('aria-invalid', 'true')` after Escape then `button.click()` is where it times out after about 15 s.

## Work

1. Reproduce it: loop the full UI suite until the test fails, and keep the failing output.
2. Find the cause: say in the report exactly which event or state arrives in which order when it fails. "Flaky" and "slow machine" are not causes.
3. Fix the cause where it is: in the component when the user could meet the same race (then a real defect is fixed), otherwise in the test. Never lengthen a timeout, add a retry, add a sleep, skip the test or weaken the assertion.
4. Run the full suite at least 25 times in a row with the fix and see every run pass.
