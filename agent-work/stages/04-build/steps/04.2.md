## Goal

`runIngestCycle` reads one range from a `MidnightSource` and stores it with the cursor in one transaction, so that no failure can leave the cursor past data that is not stored (O4, D06).

## Read first

- `agent-work/architecture.md`, "Ingest" and "Store". Where it differs from D28 and D46, the decisions hold. `agent-work/decisions.md`, D06, D12, D23, D36, D38, D45 to D47, D49, D50.

## Work

Change no manifest and no file of `src/db`. `runIngestCycle` is an exported function declaration (step 04.10 builds the loop over it). The port serves hex and the tables hold `bytea`: compare as `Buffer`.

1. `runIngestCycle(deps, settings): Promise<IngestCycleOutcome>`. `deps` is `db` (an `ExplorerDatabase`, already migrated), `source`, and `inspect: (rawTransactionHex: string, notifications: readonly SignBidirectionalLifecycle['signBidirectionalEvents'][number][]) => StoredInspection` (step 04.1's: your tests pass a stub). `settings` is `network`, `signerContractAddress`, `responderContractAddress` (lower case hex), `startBlock`, `maxRange` and `tipMargin`, all required (D50). The outcome is a union: `stored` (with the range and the event count), `caught-up`, `stopped`, `superseded`, `failed` (with the cut message). With `from = (cursor ?? startBlock - 1) + 1`:
   1. No `ingest_state` row: insert one (`ON CONFLICT DO NOTHING`, then read it) with the source's genesis hash, the addresses, the start block, a null cursor and `state` `syncing` (D46).
   2. Identity (D12): the stored genesis hash equals the source's, the stored addresses and start block equal the settings', and with a cursor `blockAt(cursor_height)` has the stored hash. A difference sets `state` to `stopped` and `last_error` to the reason, and returns `stopped` with nothing else written. A null `blockAt` at the cursor fails the cycle: a source that is behind is no mismatch.
   3. `target = min(tip - tipMargin, from - 1 + maxRange)`. When `target < from`: record the tip, the success time, a null error and `state` `synced`, return `caught-up`. Otherwise read `blockAt(target)` now. Null fails the cycle.
   4. Read `eventsIn` for `from` to `target` and decode each with lib's `decodeSignetContractEvent`. For each transaction that emitted a sign bidirectional event, fetch its bytes once and call `inspect` once with all its notifications, at most 8 fetches at a time. A throw of `inspect` is stored as `{ failed: <message> }` for that transaction (D23). Another transaction is stored with null `raw` and null `inspection` (D49).
   5. One SQL transaction, in this order: the cursor update of D46 (it also sets `tip_height`, `last_success_at`, a null `last_error`, and `state` `synced` when `target` is the tip less the margin, `syncing` otherwise). No row changed: roll back, return `superseded`. Then plain inserts of the transactions and the events (a duplicate is an error, D45). Then, for every request id an inserted event declares, `INSERT ... ON CONFLICT (request_id) DO UPDATE` its `requests` row with every column recomputed from ALL the stored events of that id, and insert the caller of each new notification into `request_callers`, ignoring one already there (D36). Nothing deletes: the check greps non-test code for `DELETE FROM` and `TRUNCATE`.
2. Any other throw rolls back, writes `last_error` in a statement of its own (through `textWithoutUrlCredentials` of the api package, at most 2,000 characters, D47) and returns `failed`. A raw transaction that cannot be fetched fails the cycle (D23). A failure before the state row exists is recorded nowhere: accepted.
3. Tests against a real PostgreSQL and the in-memory source, with these titles. Place an event by rewriting its `source.transactionHash`, `blockHeight`, `blockHash` and `blockTimestamp` to its block's:
   - `the first cycle records the identity and starts at the start block`
   - `stores a range and moves the cursor together`
   - `a failing read leaves the cursor and the tables unchanged`
   - `a failure inside the transaction stores nothing`
   - `a cycle after a commit reads on from the new cursor and stores nothing twice`
   - `of two cycles from one cursor only one commits`
   - `a changed genesis hash stops the network and writes nothing`
   - `a replaced cursor block stops the network`
   - `changed contract addresses or start block stop the network`
   - `never reads past the tip less the margin, nor more than the range`
   - `a response stored before its request completes the same row`
   - `stores every caller of a request notified twice`
   - `the request rows equal a rebuild from the stored events after any order of arrival` (the same events ingested in several orders and ranges, and seeded with `seedNetworkEvents` into another network's schema: the two `requests` and `request_callers` tables are equal)
   - `stores an event that does not decode without a request row`
   - `inspects a transaction once with all its notifications and stores a failed inspection` (a stub that returns `{ failed }`, and one that throws)
   - `stores a transaction without a notification uninspected`
   - `a transaction that cannot be fetched fails the cycle`
   - `the recorded error carries no query string` (a call that fails after the first cycle)
