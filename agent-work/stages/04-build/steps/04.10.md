## Goal

The configuration popover is read-only: it shows the selected network's configuration as the
network service reports it and the browser-side endpoints of the build, and nothing can be typed
into it but the network. A line in the Midnight bar shows the indexing status: processed block,
head block, and a halt with its reason.

## Work

1. `components/midnight/use-midnight-network-status.ts`: `useMidnightNetworkStatus()` polls
   `listNetworks` with `usePolledQuery` and returns the status of the network the URL selects,
   or that no backend is configured, or the load's error.
2. `midnight-configuration.tsx`: keep the trigger, the popover and the network select, which
   still rewrites `networkId` in the URL. Replace the inputs and the reset button by a
   read-only list: signer address, responder address, MPC root public key, start block and the
   indexer's HOST, from the network status. Then the build's own endpoints: the backend URL,
   the two EVM RPC URLs and the MPC output cache URL. A network that is not configured says so
   in place of the first group. Values are copyable where the app has a component for it.
3. Do not remove `setConfig`, `resetDefaults` or the override state from `MidnightContext`:
   other files still call them until stage 05. After this step the popover calls none of them.
4. `components/midnight/indexing-status.tsx`: one line for the bar: "Indexed to block N of M"
   with the processed block's time, a distinct treatment while the backend is behind by more
   than a constant number of blocks, and, when the network is halted, a destructive `Badge`
   with the halt reason behind a tooltip. Nothing when no backend is configured. Mount it in
   `midnight-app-bar.tsx`, between the tabs and the configuration button.
5. Any number or time formatter you need goes in `lib/format.ts` with a test, beside the
   existing ones.
6. Tests with the fake network service: a running network, one far behind, a halted one with
   its reason, one not configured, no backend, and the popover showing no input but the select.
7. `yarn lint`, `yarn build`, `yarn check`. Commit.
