## Goal

`createPostgresExplorerService(db, networks)` implements the api package's `ExplorerService` over the `lifecycle` view and `ingest_state`, and answers exactly as the in-memory service does.

## Read first

- `packages/api/src/`: the `ExplorerService` interface, the wire schemas and the in-memory service, whose rules you match.
- `packages/backend/src/db/schema.ts`, `testing.ts` and the migrations.

## Work

1. `networks` is the list of served networks with their display configuration (the caller passes it, with the source URL already stripped of its query string). `sync` comes from each network's `ingest_state`. A network whose schema has no state row yet is `starting`.
2. `lifecycles`: filter and order on `requests` alone (`first_event_id DESC`, keyset on `before`), then read those rows from the view. `search` strips an optional `0x`, lower cases, and matches a fragment of `request_id` or `caller` with `LIKE`, escaping `%` and `_`. `excludeCallers` never hides a request with no caller. The three counts are read in the same transaction as the page.
3. `lifecycle` reads one view row by `request_id`. `callers` is the distinct non-null callers.
4. Every value from the database is validated with the wire schemas before it is returned. Every input is a bound parameter: no string is concatenated into SQL.
5. Tests against a real PostgreSQL, seeded through SQL helpers of your own in `src/service/`, with these titles:
   - `answers as the in-memory service for the shared seed` (run the api package's exported seed through both and compare every method's answer)
   - `pages through 500 requests without repeating or skipping one`
   - `search matches a fragment in any case with or without 0x`
   - `search treats percent and underscore as text`
   - `excluding callers keeps requests that name no caller`
   - `counts matching and total requests and total events`
   - `reports starting, syncing, synced and stopped`
   - `an unknown network is the typed error`
   - `the newest page of 100,000 requests answers within 200 ms`

## Done when

`checks/04.3.sh` proves the nine tests exist and pass against a real PostgreSQL. It cannot prove the SQL is free of injection: the final review reads it.
