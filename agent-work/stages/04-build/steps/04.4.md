## Goal

`loadBackendConfig(env)` turns the environment of section 10 into one immutable, validated
object: the server settings, and for each of the four networks either a complete configuration
or the fact that it is not configured. An invalid value stops it with an error that names the
variable and never shows a value.

## Read first

- `../../../architecture.md`, sections 3 and 10.
- `packages/ui/src/lib/midnight/network.ts:100-300`: how the UI reads the same kinds of value
  today (`readOptionalEnv`, the Blockfrost URL, the SDK's defaults for preprod).
- In the demo checkout the `backend-patterns` pack names: `src/lib/config/server-config.ts:55-105`.

## Work

1. `config/backend-config.ts`: the config type first, then one zod schema over the environment,
   then `loadBackendConfig(env: NodeJS.ProcessEnv)`. It takes the environment as an argument
   and reads `process.env` nowhere.
2. Server settings: `DB_CONNECTION_STRING` (required), `BACKEND_ROLES` (a non-empty set out of
   `ingest` and `serve`, defined once as a closed set), `HTTP_PORT`, `CORS_ALLOWED_ORIGINS`
   (each an origin: scheme and host, no path), `LOG_LEVEL`.
3. Per network, from the `MIDNIGHT_<NETWORK>_*` variables, for every member of the SDK's
   network set: the indexer URL is the explicit `_INDEXER_URL`, else the Blockfrost URL built
   from `_BLOCKFROST_PROJECT_ID`. Addresses and the root key are the explicit value in
   canonical form, else the SDK's published value, caught when the SDK throws for a network it
   publishes nothing for. The start block is the explicit value, else preprod's built-in
   3386746. A network with all five is `{ configured: true, ... }`, any other is
   `{ configured: false, missing: [the variable names] }`. The URL's Blockfrost host for each
   network other than preprod is NOT known: say in the report what you found, and leave those
   networks to `_INDEXER_URL`.
4. `ETHEREUM_SEPOLIA_RPC_URL` and `ETHEREUM_MAINNET_RPC_URL`: optional, keyed by chain id
   (11155111 and 1) in the result.
5. `indexerHost(config)`: the host of the indexer URL and nothing else of it. This is the one
   function a service may use to describe the indexer (D21).
6. Errors: built with `z.prettifyError`, and checked by a test to contain the variable's name
   and NOT the value given, for every variable that can hold a secret.
7. Tests, table-driven: the empty environment (every network not configured, and which
   variables each misses). Preprod from a project id alone. An explicit indexer URL beating
   the project id. An address with `0x` and capitals made canonical. A bad address, a bad
   root key, a negative start block, a role that does not exist, an origin with a path. The
   returned object is frozen.
8. `packages/backend/.env.example`: every variable of section 10, with local values where they
   are not secret and empty where they are, each under a one-line comment.
9. `yarn lint`, `yarn build`, `yarn check`. Commit.
