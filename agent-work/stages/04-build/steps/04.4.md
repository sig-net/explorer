## Goal

`parseBackendEnv(env)` turns the process environment into validated, immutable configuration, and `createHttpApp({ service, corsOrigins, ready, logError })` is the backend's Hono app: the api routes, CORS, and the liveness and readiness endpoints (D09, D14).

- `packages/ui/src/lib/midnight/network.ts:40-70` and `:200-290`: preprod's Blockfrost URL, how the project id joins it, the SDK's addresses and the earliest blocks of the published contracts, to keep the same defaults.

## Work

Change no manifest.

1. The environment, validated with zod, every failure naming its variable and never printing a value:
   - `EXPLORER_DATABASE_URL` (required), `EXPLORER_PORT` (default 8080), `EXPLORER_CORS_ORIGINS` (comma separated origins, required, `*` allowed alone).
   - `EXPLORER_MIDNIGHT_NETWORKS`: comma separated network ids that are served, at least one, each a member of lib's `MIDNIGHT_NETWORKS`. Each needs its source: `EXPLORER_MIDNIGHT_<NETWORK>_INDEXER_URL`, or for preprod `EXPLORER_MIDNIGHT_PREPROD_BLOCKFROST_PROJECT_ID`, from which the Blockfrost indexer URL is built.
   - Per network, optional: `..._SIGNER_CONTRACT_ADDRESS`, `..._RESPONDER_CONTRACT_ADDRESS` (parsed with lib's `parseContractAddressHex`. Default: the SDK's for that network, an error when the SDK publishes none), `..._START_BLOCK` (default: for preprod's published contracts 3,386,746, otherwise required).
   - `EXPLORER_POLL_INTERVAL_SECONDS` (default 30, D29), `EXPLORER_TIP_MARGIN_BLOCKS` (default 6, D28), `EXPLORER_MAX_RANGE_BLOCKS` (default 2,000, D21). These three defaults are exported constants and exist nowhere else (D50).
2. The configuration is deeply `readonly`. Each network carries an `ExplorerNetworkConfig` (the source URL whole, token included: the api package cuts it for the wire, D13 and D39) with the three ingest settings beside it. The configuration type has no method that prints it, and a test proves that no error message of the parser holds a value of the environment.
3. `createHttpApp`: mounts `explorerApiRoutes(service)` at `/`, answers CORS for the configured origins on GET and the preflight, `GET /healthz` answers 200 while the process runs, `GET /readyz` answers 200 when `ready()` is true and 503 otherwise. An unknown path answers 404 with an `ErrorWire` of code `not_found`. An unexpected error answers 500 with an `ErrorWire` of code `unavailable` and a fixed message, and its message reaches `logError` through `textWithoutUrlCredentials` (D47).
4. Tests, with these titles:
   - `parses a full environment`
   - `names the variable that is missing or invalid and prints no value`
   - `builds preprod's source from a Blockfrost project id`
   - `takes the SDK's addresses and preprod's start block by default`
   - `takes the poll interval, the tip margin and the range from the decisions by default` (30, 6 and 2,000)
   - `refuses a network that is not a Midnight network or has no source`
   - `answers a preflight and a GET for an allowed origin`
   - `sends no CORS header to another origin`
   - `healthz is 200 and readyz follows ready`
   - `serves the api routes over the in-memory service` (through `createExplorerApiClient` with the app's `request` as its `fetch`)
   - `an unknown path answers not_found in the api's error body`
   - `an unexpected error answers 500 with no detail and is logged without a token`
