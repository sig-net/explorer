## Goal

`parseBackendEnv(env)` turns the process environment into validated, immutable configuration, and `createHttpApp({ service, corsOrigins, ready })` is the backend's Hono app: the api routes, CORS, and the liveness and readiness endpoints (D09, D14).

## Read first

- `packages/api/src/`: `explorerApiRoutes` and the in-memory service your tests serve.
- `packages/ui/src/lib/midnight/network.ts`: how the UI names preprod's Blockfrost URLs and takes the SDK's addresses, to keep the same defaults.

## Work

1. The environment, validated with zod, every failure naming its variable and never printing a value:
   - `EXPLORER_DATABASE_URL` (required), `EXPLORER_PORT` (default 8080), `EXPLORER_CORS_ORIGINS` (comma separated origins, required, `*` allowed alone).
   - `EXPLORER_MIDNIGHT_NETWORKS`: comma separated network ids that are served. Each needs its source: `EXPLORER_MIDNIGHT_<NETWORK>_INDEXER_URL`, or for preprod `EXPLORER_MIDNIGHT_PREPROD_BLOCKFROST_PROJECT_ID`, from which the Blockfrost URL is built.
   - Per network, optional: `..._SIGNER_CONTRACT_ADDRESS`, `..._RESPONDER_CONTRACT_ADDRESS` (default: the SDK's for that network, an error when the SDK publishes none), `..._START_BLOCK` (default: for preprod's published contracts 3,386,746, otherwise required).
   - `EXPLORER_POLL_INTERVAL_SECONDS` (default per `gate A10`), `EXPLORER_TIP_MARGIN_BLOCKS` (default per `gate A7` and `gate A8`), `EXPLORER_MAX_RANGE_BLOCKS` (default 2,000).
2. The configuration type keeps the source URL whole for the ingest and exposes `displaySourceUrl`, the same URL with no query string, for the service (D13).
3. `createHttpApp`: mounts the api routes, answers CORS for the configured origins on GET and the preflight, `GET /healthz` answers 200 while the process runs, `GET /readyz` answers 200 when `ready()` is true and 503 otherwise. An unknown path answers the api's `not_found` error body. An unexpected error answers 500 with no detail and is logged without a query string.
4. Tests, with these titles:
   - `parses a full environment`
   - `names the variable that is missing or invalid and prints no value`
   - `builds preprod's source from a Blockfrost project id`
   - `takes the SDK's addresses and preprod's start block by default`
   - `the display source url has no query string`
   - `answers a preflight and a GET for an allowed origin`
   - `sends no CORS header to another origin`
   - `healthz is 200 and readyz follows ready`
   - `serves the api routes over the in-memory service`
   - `an unexpected error answers 500 with no detail`
