## Goal

`IndexerChainSource` implements `MidnightChainSource` over a Midnight indexer's GraphQL, with
`eventsInRange` complete or throwing as the design demands. It is tested against recorded
indexer answers and scripted faults, and by one opt-in test against preprod.

## Read first

- `../../../architecture.md`, sections 5 and 6.
- `../../../decisions.md`: the outcomes of G01, G02, G03, G06, G07, G08 and G09.
- The stage's `stage.md`, beside `steps/`: gate G18, which you answer.
- `packages/backend/src/chain-source/chain-source.ts`: the interface and what each method
  promises.
- `agent-work/probes/contract-events-paging.mjs` and `agent-work/probes/chain-lookups.mjs`: queries that are known
  to work against preprod.

## Work

1. Answer G18 from stage 01's numbers and say which way you went, and why, in your report
   under a line starting `G18:`.
2. `indexer-chain-source.ts`: the class, built from an indexer URL and a `fetch`. A small
   `graphql.ts` beside it posts a query and turns a transport failure, a status that is not
   200 and a GraphQL `errors` entry into one error type whose message never holds the URL or
   the response body.
3. `eventsInRange(contracts, range)`: read both contracts (one read when the two addresses are
   equal, with both roles), page until done, and REFUSE the result, by throwing, unless: ids
   ascend strictly within each contract's pages, every event's block lies inside the range,
   no id repeats, and, where G03 asked for it, a second walk returns the same ids. Merge the
   contracts by id and assign `blockPosition` per block from 0, as G01 decided. Normalise the
   payload to the SDK's 256-byte form.
4. `headBlock`, `blockAt`, `rawTransaction`, `contractExistsAt`: each with the query its gate
   chose. `blockAt` of a height above the head throws. `rawTransaction` of an unknown hash
   throws an error a caller can tell from a transport failure.
5. Pacing: at most the request rate G07 allows, enforced inside the class, not by its callers.
6. Tests with a scripted `fetch`, no network: a range of three pages across two contracts
   comes back merged and positioned. One contract in both roles. And each refusal: a page
   whose ids fall, a repeated id across pages, an event outside the range, a second walk that
   differs, a GraphQL error, a 429, a body that is not JSON. Record two real answers from
   preprod as fixtures under `fixtures/` (run the probes' queries once), with no URL in them.
7. `indexer-chain-source.preprod.test.ts`, skipped unless `MIDNIGHT_PREPROD_INDEXER_URL` is
   set: the first 5000 blocks from 3386746 read as one range equal the same blocks read as
   five ranges, and `blockAt(3386746)` has the hash the probes recorded.
8. `yarn lint`, `yarn build`, `yarn check`, then the preprod test once with the variable set
   as the `probes` pack's command sets it. Commit.

## Done when

`checks/04.1.sh` proves the class and its tests exist, each refusal is tested by name, no file
of the folder can print a URL, all checks pass, and the preprod test passes with the secret set.
It cannot prove completeness against an indexer that lies: that limit is the design's, stated in
section 5.
