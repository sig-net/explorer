## Goal

`createIndexerSource({ queryUrl, signerContractAddress, responderContractAddress })` implements `MidnightSource` over the Midnight indexer, and `packages/backend/src/inspection/` holds `inspectTransactionForStorage`, which gives a transaction's `StoredInspection` (D38, D49). Both are tested without the network and once against preprod.

## Work

Every dependency is installed: change no manifest.

1. `src/inspection/sign-bidirectional-transaction-inspection.ts`, with its test and the fixture copied beside it. Take the UI module's logic as it is and give it one export:
   `inspectTransactionForStorage(rawTransactionHex: string, notifications: readonly SignBidirectionalLifecycle['signBidirectionalEvents'][number][]): StoredInspection` (the element type is lib's decoded sign bidirectional event: `source.id`, `requestId`, `record`).
   - The bytes deserialise once and the call chains are read once. A failure there gives `{ failed: reason }` for the whole transaction.
   - Under each event's id (`String(source.id)`): `{ cell }` with the cell its caller's transcript wrote at `record.requestsPath` under `requestId`, in the wire form (`RequestCellWire`), or `{ cell: null }` when there is no such write. A cell that does not decode as an evmType2 record, or any other throw for that one event, gives `{ failed: reason }` for it and leaves the others as they are.
   - It never throws. `ContractCallNode` and `RequestCellWire` come from `@sig-net/explorer-api`: declare neither again.
   - Do not delete or change the UI's copy: step 04.6 deletes it.
2. `src/source/indexer/`: the adaptor.
   - `eventsIn` reads each distinct contract through the SDK's `signetEventSourceFromIndexer` and merges by `id`, ascending. A signer and responder at one address are read once and every event carries both roles. It keeps the fields of `StoredSignetMiscEvent` alone, and throws when an event lies outside the asked range.
   - `finalisedTip`, `blockAt`, `genesisHash` and `rawTransaction` are GraphQL queries of your own (the indexer pack has each), each response validated with zod. `rawTransaction` throws when the indexer holds no transaction with that hash.
   - Hashes and raw bytes are returned lower case without `0x`.
   - Every request ends after `timeoutMs` (an option, 30,000 by default, D50) as a rejection.
   - No error this module throws carries the URL's query string: use the SDK's `redactUrlQuery`.
3. Unit tests stub `fetch` with recorded responses. Titles:
   - `merges both contracts by event id`
   - `reads a contract configured in both roles once`
   - `rejects an event outside the range`
   - `answers null for a block above the tip`
   - `rejects a response that does not validate`
   - `rejects when the indexer holds no such transaction`
   - `a request that never answers is rejected after the timeout`
   - `an error carries no query string`
   - `stores the call chains and the request cell of the fixture transaction` (the cell equals `PREPROD_REQUEST_CELL_WIRE` of `@sig-net/explorer-api/testing`, under the event's id)
   - `stores a null cell for a notification the transaction does not write`
   - `stores one failed notification beside a read one`
   - `stores a transaction that does not deserialise as failed`
4. One live test, `reads preprod`, which runs only when `EXPLORER_TEST_PREPROD_INDEXER_URL` is set (`describe.skipIf`, and the exit check sets it): the genesis hash is the one the indexer pack gives, the events of blocks 3,389,203 to 3,389,208 include the first signer and the first responder event, and the first signer event's transaction inspects to a cell that decodes to a request for chain 11155111.
