## Goal

`createIndexerSource({ queryUrl, signerContractAddress, responderContractAddress })` implements `MidnightSource` over the Midnight indexer, and `packages/backend/src/inspection/` holds the transaction inspection, both tested without the network and once against preprod.

## Read first

- `packages/backend/src/source/port.ts` and `in-memory.ts`.
- `packages/ui/src/lib/midnight/sign-bidirectional-transaction-inspection.ts`, its test and its fixture.
- `packages/ui/src/lib/midnight/indexer-block-height.ts` and `sign-bidirectional-transaction-loader.ts:9-48`: the two queries the UI sends by hand.

## Work

1. Copy the inspection module, its test and its fixture to `packages/backend/src/inspection/` unchanged in behaviour. Add `inspectionForStorage(rawHex, requestId, notification)`, which returns what the `transactions.inspection` column stores: the call chains with the request cell as the wire carries it, or `{ failed: reason }` when the inspection throws (D23). Do not delete the UI's copy: step 04.6 does.
2. `src/source/indexer/`: the adaptor.
   - `eventsIn` reads each distinct contract through the SDK's `signetEventSourceFromIndexer` and merges by `id`. A signer and responder at one address are read once, with both roles. It throws when an event lies outside the asked range.
   - `finalisedTip`, `blockAt`, `genesisHash` and `rawTransaction` are GraphQL queries of your own, each response validated with zod.
   - Hashes are returned lower case without `0x`.
   - No error this module throws carries the URL's query string. Use the SDK's `redactUrlQuery`.
3. Unit tests stub `fetch` with recorded responses. Titles:
   - `merges both contracts by event id`
   - `reads a contract configured in both roles once`
   - `rejects an event outside the range`
   - `answers null for a block above the tip`
   - `rejects a response that does not validate`
   - `an error carries no query string`
   - `stores a failed inspection with its reason`
   - `stores the call chains and the request cell`
4. One live test, `reads preprod`, which runs only when `EXPLORER_TEST_PREPROD_INDEXER_URL` is set: the genesis hash is `df83...361b` (the indexer pack has it whole), blocks 3,389,203 to 3,389,208 hold the first signer and responder events, and the first signer event's transaction inspects to a request for chain 11155111.

## Done when

`checks/04.1.sh` proves the eight unit tests and the live test pass. It cannot prove the adaptor never drops an event: review 04.8 attacks that.
