## Goal

`agent-work/probes/live-preprod.out.json` holds the result of running the backend image against preprod from the contracts' deployment to the tip, killing it once on the way, and loading the built UI against it: the evidence for O1, O2 and O4.

## Read first

- `agent-work/probes/live-preprod.sh` and `agent-work/probes/live-ui.mjs`: the probe, already written. If a name in it no longer matches what stage 4 and step 05.1 built (an environment variable, a route, a table), correct the probe in your report's terms and stop: the orchestrator repairs it. Do not change it yourself, it is outside your scope.

## Work

1. `yarn install --immutable` at the root of your worktree.
2. Run `bash agent-work/probes/live-preprod.sh`. It runs for up to 45 minutes, longer than one tool call allows: start it detached with its output in a log file, then wait for it in the foreground until the process has ended. Do not end your turn while it runs.
3. Read the log through `redact`. Check that `agent-work/probes/live-preprod.out.json` holds no token: `grep -c project_id` on it must print 0.
4. Check that the probe removed its containers and its preview server: `docker ps -a --format '{{.Names}}' | grep explorer-live` prints nothing.
5. Commit the output and `agent-work/probes/live-preprod.png` on your step's branch and push.
6. Report, as numbers: `storedEvents`, `indexerEvents`, `processedBlock`, `startBlock`, `killedAtBlock`, `killedBeforeSynced`, `uiRows`, `uiExpandedRowVerified`, `uiRequestsToMidnight`, `secondsToSynced`.

## Done when

`checks/05.2.sh` proves the output exists and says: the stored events equal the indexer's count over the same blocks, the backend was killed between its first commit and the tip and still ended synced, the UI rendered rows and expanded one, and the browser sent no request to a Midnight indexer or node. It cannot prove the page looks right: the orchestrator opens the screenshot the probe saved beside the output.
