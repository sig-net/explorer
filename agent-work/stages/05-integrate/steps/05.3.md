## Goal

Everything a person needs once `agent-work/` is removed is in the repository's own documentation: how the system is built and run, and why it is built so.

## Read first

- `README.md`, whole: it describes the app as it was before this task.
- `agent-work/architecture.md` and `agent-work/decisions.md`: the source of the design and the reasons.
- `packages/backend/src/config/`: the environment variables as built. `packages/backend/src/main.ts`, `packages/backend/Dockerfile`, `packages/backend/compose.yaml`.
- The reports' lists the orchestrator puts in your brief: the README hits of step 04.7 and the workflow lines of step 02.1.

## Work

1. Root `README.md`: what the explorer is now (UI, backend, PostgreSQL, one diagram-free paragraph each), the workspace layout, the scripts, how to run all of it locally against preprod (PostgreSQL through `db:up`, the backend with a Blockfrost project id, the UI with `VITE_EXPLORER_API_URL`), and how to run the tests (they need `EXPLORER_TEST_DATABASE_URL`). Run every command you quote, verbatim, before you write it.
2. `packages/backend/README.md`: every environment variable with its default, the endpoints, the health endpoints, the image (build and run commands), the ingest in plain words (the processed block moves only with its data), what `stopped` means and how an operator wipes a network, what a Kubernetes deployment must provide (one replica, the variables, the probes, a PostgreSQL 17 with `pg_trgm` available).
3. `packages/ui/README.md`: the app's own reference, moved from the root README and corrected: delete every section about the indexer, Blockfrost, the starting block, the event store and the ledger WebAssembly, and describe the backend URL, the read only configuration and the sync state.
4. `DECISIONS.md` at the root: each decision of `agent-work/decisions.md` that a maintainer could be tempted to undo, with its reason and the measurement behind it (one schema per network, the maintained `requests` table with the view, the processed block moved in the same transaction, the backend inspecting transactions, raw payloads on the wire, the indexer as the source and what a node source would take, stopping on a mismatch). Written as what is and why, with no history of the task.
5. `AGENTS.md`: correct every path and rule the task made untrue, and add under "Boundaries and ownership": the UI never reads a Midnight indexer or node, and no response or log carries a URL's query string.
6. `grep -rniE 'blockfrost|indexer url|starting block|agent-work' README.md packages/*/README.md DECISIONS.md` and read every hit: each must be true of the code as merged, and none may point a reader into `agent-work/`.
7. In your report, under a heading `FOR THE USER`, the exact change each file under `.github/workflows/` needs.

## Done when

`checks/05.3.sh` proves the documents exist, name every environment variable the configuration parses, and name nothing the task removed. It cannot prove the prose is true: the final review runs the quoted commands.
