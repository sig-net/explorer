## Goal

The `probes/` folder of stage 01 and every mention of it are gone (D23). The repository holds
only what the product needs.

## Read first

- `.dockerignore`: the `probes` line and its comment.

## Work

1. `git rm -r probes`.
2. In `.dockerignore`, remove the line `probes` and the comment line above it. Change nothing
   else in the file.
3. The mover pays: `git grep -n 'probes' -- . ':!agent-work'`. Every hit is a pointer to
   something that no longer exists. A hit in `.dockerignore` you fix. A hit anywhere else is
   outside your scope: list it in your report with its file and line, and report BLOCKED if
   there is one.
4. `yarn install --immutable`, `yarn lint`, `yarn format:check`. Commit.

## Done when

`checks/07.3.sh` proves the folder is gone, nothing outside `agent-work/` mentions it, the
`agent-work` line of `.dockerignore` is still there, and the lint and format checks pass.
