## Goal

The UI holds no code that reads a Midnight indexer and no setting that only such code needed.
Its configuration is `VITE_EXPLORER_BACKEND_URL`, `VITE_MIDNIGHT_DEFAULT_NETWORK` and the
browser-side endpoint overrides. Every name this removes is gone from the whole repository.

## Read first

- `../../../architecture.md`, section 8. `../../../decisions.md`: D09, D10.
- The `ui-census` pack's list of what goes, then `git grep` for each name to see what still
  imports it after stage 04.
- `packages/ui/src/components/contexts/MidnightContext.tsx`,
  `packages/ui/src/lib/midnight/network.ts`, `packages/ui/src/lib/explorer-env.ts`,
  `packages/ui/src/vite-env.d.ts`, `docker/30-explorer-env.sh`.

## Work

1. Census before deleting: for each file below, `git grep` its exports. A consumer that stage
   04 should have moved and did not is a finding: report it, and move it only if the change is
   an import swap. Anything larger: report BLOCKED.
2. Delete, each with its test: `lib/midnight/signet-event-store.ts`, `indexer-services.ts`,
   `indexer-block-height.ts`, `signet-events-window.ts`,
   `components/midnight/signet-events-starting-block.tsx`,
   `components/contexts/MidnightSignetEventsContext.tsx`, and its provider in `__root.tsx`.
   Delete any fixture and helper that only they used.
3. `MidnightContext`: it keeps the selected network and the browser-side endpoints (the two
   EVM RPC URLs, the MPC output cache URL). Remove the indexer services, the overrides,
   `setConfig`, `resetDefaults` and `isDefaultConfig`. Re-read the context's name, its value
   type and every field name as they stand after the removal, and rename what no longer says
   what it holds.
4. `network.ts`: remove the indexer and node URLs, the Blockfrost URLs and project id, the
   signer and responder addresses, the root key, the events' starting block and every parser
   that only they used. `MidnightNetworkConfig` holds the browser-side endpoints alone: rename
   it if its name now promises more than it holds. The MPC output cache URL keeps its SDK
   default for preprod.
5. `vite-env.d.ts` and `explorer-env.ts`: drop the variables of the removed settings. Keep
   `VITE_EXPLORER_BACKEND_URL`, `VITE_MIDNIGHT_DEFAULT_NETWORK`,
   `VITE_MIDNIGHT_ETHEREUM_MAINNET_RPC_URL`, `VITE_MIDNIGHT_ETHEREUM_SEPOLIA_RPC_URL`,
   `VITE_MIDNIGHT_PREPROD_MPC_OUTPUT_CACHE_URL`.
6. `docker/30-explorer-env.sh` writes every `VITE_MIDNIGHT_*` variable into `env.js`. Make it
   also write `VITE_EXPLORER_BACKEND_URL`, and nothing else new: `VITE_EXPLORER_VERSION` is the
   build's. Run the script against a temporary folder to see its output.
7. The mover pays. For every deleted file, export and variable name: `git grep` it over the
   whole repository and fix each hit in `README.md`, `AGENTS.md`, `Dockerfile` and the code.
   In `README.md` change only what names something you removed: stage 07 rewrites the rest.
8. `yarn lint`, `yarn build`, `yarn check`, then `EXPLORER_BASE_PATH=/explorer/ yarn build`.
   Commit.

## Done when

`checks/05.2.sh` proves the six files are gone, none of the removed names is left anywhere in
the repository, the built bundle names no indexer, the WebAssembly rule holds, and all checks
pass.
