## Goal

`node packages/backend/src/main.ts audit <network>` walks that network's whole history again,
from its start block to its checkpoint, and compares it with the database: the events, the block
hashes, and the aggregate rows against a rebuild. It reports every difference, exits 0 only when
there is none, and halts the network when the chain no longer says what is stored.

## Work

1. The comparison of a range's stored events with a fresh read exists in the ingester's
   trailing re-read. The audit is its second consumer: move it to one function both call, in
   `src/audit/compare-range.ts`, and make the ingester import it. Its result lists events
   missing from the database, events the chain no longer has, and events that differ, each by
   chain position.
2. `src/audit/audit.ts`: `auditNetwork(network, options)`. It reads only, takes no lock, and
   may run beside a live ingester: it fixes its upper bound at the checkpoint it reads first.
   It walks `[start_block, checkpoint]` in ranges through the chain source, compares each
   range, and compares the stored hash of the checkpoint's block with the chain's. Then it
   rebuilds every request's row with `deriveSignRequest` from the stored events and compares
   it with the stored row, and counts rows with no events and events with no row.
3. Its result is a value: totals, and each difference with its position. The command prints it
   as lines a person can read, and as JSON with `--json`. No URL in either.
4. When the chain differs from the database (not when only the aggregate differs), the command
   sets the network `halted` with a reason that says the audit found it, in one transaction,
   exactly as the ingester halts. With `--report-only` it changes nothing. An aggregate that
   differs from its own events is reported and exits 1, and is not a halt: the chain data is
   intact and a rebuild repairs it. Add `rebuild-sign-requests <network>`, which takes the
   network's lock and rewrites the rows from the events in one transaction.
5. Register `audit` and `rebuild-sign-requests` in the command table and add their scripts.
6. Tests with the fake chain source on scratch databases, each planting ONE difference after an
   honest ingestion and asserting the audit finds exactly it: a deleted event row, a changed
   payload, an extra event row, an event the fake no longer serves, a changed block hash at
   the checkpoint, a changed aggregate row, a deleted aggregate row. And a clean history gives
   no difference and exit 0. And `--report-only` halts nothing.
7. `src/audit/audit.preprod.test.ts`, skipped unless `MIDNIGHT_PREPROD_INDEXER_URL` is set:
   ingest preprod to the head on a scratch database, audit it, expect no difference. This is
   G23.
8. `yarn lint`, `yarn build`, `yarn check`, then the preprod test with the secret set. Commit.
   Put a line starting `G23:` with `holds` or `fails` and the event count in `FINDINGS`.
