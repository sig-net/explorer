## Goal

`agent-work/probes/evm-trace.mjs` reads a mined Sepolia transaction's top call frame with
`debug_traceTransaction` from the keyed endpoint and decodes it in Node with the SDK.
`agent-work/probes/findings/evm-trace.json` answers gate G11 and tells stage 03 what the two candidate
values for the `trace` column look like as JSON.

## Read first

- `../stage.md` (the stage's file, beside `steps/`): the row G11 of the gate table.
- `src/lib/midnight/evm-transaction-output.ts:1-49`: the exact call and decode the UI makes today.
- `src/lib/midnight/evm-json-rpc.ts:1-34`: the JSON-RPC envelope and its error handling.
- `node_modules/@sig-net/midnight/dist/abi-serde.d.ts`: the declarations of `EvmTraceOutput`,
  `evmTraceOutputFromCallFrame` and `JsonValue` (search the file for the three names).

## Work

1. Run `yarn install --immutable`. Write the probe as the pack says, with one difference: its
   endpoint comes from the environment variable `SEPOLIA_FORK_RPC_URL`, which is also a secret
   that carries a key. Run it with
   `SEPOLIA_FORK_RPC_URL="$(dev-secrets get SEPOLIA_FORK_RPC_URL)" node agent-work/probes/evm-trace.mjs | redact`.
   It imports `@sig-net/midnight` and nothing else outside `node:`.
2. Find a transaction to trace: `eth_getBlockByNumber('finalized', true)`, then the first
   transaction with a `to` and an `input` longer than `0x`. Walk back up to 20 blocks until
   there is one.
3. Call `debug_traceTransaction` with `{ tracer: 'callTracer', tracerConfig: { onlyTopCall:
   true } }`, as the UI does, and time it. Pass the frame to `evmTraceOutputFromCallFrame`.
4. G11 `holds` only when the node answers a frame and the SDK decodes it without throwing.
   `fails` when the node refuses the method (record its message, which names what the endpoint
   lacks) or the SDK throws on a frame of a successful call.
5. For stage 03, put in the evidence and the numbers: the keys of the frame. Whether the frame
   survives `JSON.parse(JSON.stringify(frame))` unchanged. The type of every field of the
   decoded output, and whether it holds a `bigint` or a `Uint8Array`, which JSON cannot carry.
   The byte length of each as JSON (`frame_json_bytes`, `output_json_bytes`, the second -1 when
   it cannot be made JSON). `trace_ms`.
6. Also record, without letting them change the verdict: what the node answers for a hash of
   64 zeros (the design never caches a miss, so the service must tell a miss from a failure),
   and, if the 20 blocks held a transaction whose receipt `status` is `0x0`, what the SDK does
   with its frame. `numbers.reverted_seen` is 1 or 0. `head` is the finalised block's number.
7. Support `--verdicts` for G11. Write the findings file, then run `yarn lint`.
   Commit both files.

## Done when

`checks/01.9.sh` proves the findings file has gate G11 with evidence and the four numbers, and
that running the probe again gives the same verdict. It cannot prove the description of the two
JSON shapes: the stage 03 planner reads the evidence against the SDK's declaration.
