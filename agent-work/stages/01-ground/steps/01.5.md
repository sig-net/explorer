## Goal

`probes/head-consistency.mjs` watches the preprod indexer's head for at least 20 minutes and
answers gates G03, G04 and G05. Its answers are in `probes/findings/head-consistency.json`. The
no-gaps guarantee of the design rests on these three more than on anything else.

## Read first

- `../stage.md` (the stage's file, beside `steps/`): the rows G03, G04 and G05 of the gate table.
- `../../../architecture.md`, section 5 only: the loop these gates protect.

## Work

1. Before any code, find out from the indexer's own source whether it indexes finalised blocks
   only or the best chain. The source is the public repository `midnightntwrk/midnight-indexer`
   (read it with `gh` or over HTTPS, never clone it into this repository). Look for where the
   chain indexer subscribes to the node. Quote the file, the line and the commit in your report.
   If you cannot find it in a bounded search, say so and go on: the observation stands alone.
2. The Signet contracts emit a few events a day, too few to watch. Find a busy contract: read
   the last 300 blocks with `block(offset: { height }) { transactions { contractActions {
   address } } }`, count actions by address, and keep the two busiest addresses whose
   `contractEvents` are not empty. If no contract on preprod emitted in those blocks, widen once
   to 3000 blocks, then go on with the Signet contracts alone and expect `not-observed`.
3. Run `yarn install --immutable`. Write the probe as the pack says. Its loop, for `--seconds N`
   (default 1500): every 2 seconds read the head. On each new head H, at once: read the hash of
   H, and read the watched contracts' events with `fromBlock: H-20, toBlock: H`. For every
   event id, remember the head it was FIRST seen at. For every height, remember every hash seen.
4. When the loop ends, read again the hash of every height seen and every window read.
   - Lag of an event = the head it was first seen at, minus its block height, when it was
     missing from an earlier read whose head was already at or above its block. Otherwise 0.
   - A replaced block = a height that answered two different hashes at any time.
5. G03, inside the same run: pick a closed range at least 50 blocks below the head that holds
   at least 30 events of a watched contract, walk it by `offset` with `limit: 10` at the start,
   in the middle and at the end of the run, and compare the three id lists. With no such range,
   use the Signet contracts' whole history with `toBlock` fixed at the first head minus 50.
6. Verdicts, strictly:
   - G03 `holds` only with three identical walks of at least 3 pages each, else `fails` on any
     difference, else `not-observed`.
   - G04 `holds` only with at least 20 events first seen during the run and a largest lag of 0.
     `fails` with any lag above 0. Otherwise `not-observed`.
   - G05 `holds` only with at least 200 heads seen, no replaced block, AND a source reading
     from item 1 that says finalised blocks only. `fails` with any replaced block. Otherwise
     `not-observed`.
7. Numbers to write: `observation_seconds`, `heads_seen`, `events_first_seen`,
   `max_event_lag_blocks`, `replaced_blocks`, `max_replacement_depth`, `walk_pages`,
   `head_interval_p50_ms`, `head_interval_max_ms`.
8. Run it once in full. Write the findings file, run `yarn format`, then `yarn lint` and
   `yarn format:check`. Commit both files. In `FINDINGS`, say what `SAFETY_MARGIN`,
   `REREAD_BLOCKS` and `POLL_INTERVAL` you would default to, and why.

## Done when

`checks/01.5.sh` proves the findings file has the three gates and nine numbers, that the run
lasted at least 1200 seconds over at least 150 heads, and that each `holds` agrees with the
numbers beside it. It does not run the probe again, which takes 25 minutes, and it cannot prove
the source reading: the orchestrator checks the quoted file and line.
