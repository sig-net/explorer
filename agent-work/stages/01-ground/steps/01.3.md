## Goal

`agent-work/probes/indexer-soak.out.json` holds the summary of a 30 minute run of the soak probe against preprod, which the stage's three gates are read from.

## Read first

- `agent-work/probes/indexer-soak.mjs`: the probe, already written. Do not change it. If it fails for a reason in its own code, stop and report the failure.
- `agent-work/stages/01-ground/stage.md`: the gates, so that your report gives the numbers they read.

## Work

1. From the root of your worktree run `yarn install --immutable`, so that the SDK resolves.
2. Run the probe for 30 minutes. It runs longer than one tool call allows: start it detached with its output in a log file, then wait for it in the foreground until the process has ended. Do not end your turn while it runs.
   ```bash
   P="$(dev-secrets get MIDNIGHT_PREPROD_BLOCKFROST_PROJECT_ID)"
   IDX="https://midnight-preprod.blockfrost.io/api/v0?project_id=$P" \
   NODE_RPC="https://rpc.midnight-preprod.blockfrost.io?project_id=$P" \
   LOG="$(mktemp)"
   DURATION_MIN=30 nohup node agent-work/probes/indexer-soak.mjs > "$LOG" 2>&1 &
   ```
3. When it has ended, read the log through `redact`. The summary is written to `agent-work/probes/indexer-soak.out.json`. Check that the file holds no token: `grep -c project_id` on it must print 0.
4. Commit the summary on your step's branch and push.
5. In your report give, as numbers: `elapsedMinutes`, `polls`, `failedPolls`, the block range, `eventsFirstRead`, `lateEvents`, `lateEventMaxBlocksBelowTip`, `vanishedEvents`, `tipAheadOfFinalityPolls`, `tipAheadOfFinalityMaxBlocks`, `tipHashMismatches`, `calls` and `statuses`. Give no opinion on the gates: the orchestrator decides them.

## Done when

`checks/01.3.sh` proves the summary exists, covers at least 30 minutes, 200 polls and 200 blocks, holds every number the gates read and no token. A summary with `error` set fails it: run the probe again, and report BLOCKED if it fails twice. It cannot prove the numbers are honest: the orchestrator compares the report with the file.
