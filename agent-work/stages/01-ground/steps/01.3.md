## Goal

Git ignores every environment file except an example, anywhere in the repository. The step is
trivial on purpose: it proves that a subagent of this model follows a brief, commits on its
branch and files a report.

## Read first

- `.gitignore:1-32`

## Work

1. In `.gitignore`, after the `# Build output` block, add a block headed `# Environment files`
   with three lines: `.env`, `.env.*` and `!.env.example`.
2. Change nothing else in the file. Commit.
3. Run these and put their output in your report:
   `git check-ignore -v .env packages/backend/.env .env.local` and
   `git check-ignore -v .env.example packages/backend/.env.example || echo "examples are tracked"`.

## Done when

`checks/01.3.sh` proves git ignores `.env`, `.env.local` and `packages/backend/.env`, does not
ignore `.env.example` at either depth, and that the branch only adds lines to the file.
