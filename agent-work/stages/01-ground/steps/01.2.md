## Goal

`agent-work/probes/findings/README.md` exists in your worktree and says how a findings file is
read. The step is trivial on purpose: it proves that a subagent of this model follows a brief,
commits on its branch and files a report.

## Read first

nothing

## Work

1. Write `agent-work/probes/findings/README.md` (the path is relative to the root of your
   worktree), at most 10 lines. It says: the folder holds one JSON file for each probe, named
   after the probe, written by the probe itself. Each gate in a file carries a verdict and
   one sentence of evidence. `holds` and `fails` come from an observation that could have gone
   the other way, and `not-observed` means the probe could not put the question to the test.
2. Commit.

## Done when

`checks/01.2.sh` proves the file exists, names the three verdicts and stays within 10 lines. It
cannot prove the text reads well: the orchestrator reads it.
