## Goal

The Docker build context leaves the `probes` folder out. The step is trivial on purpose: it
proves that a subagent of this model follows a brief, commits on its branch and files a report.

## Read first

- `.dockerignore:1-32`

## Work

1. At the end of `.dockerignore`, after the `agent-work` entry, add a line holding exactly
   `probes`, under a one-line comment saying the folder holds one-off scripts that no image
   builds from.
2. Change nothing else in the file. Commit.

## Done when

`checks/01.2.sh` proves the file has a line that is exactly `probes`, still has its `agent-work`
and `.env*` lines, and that the branch changes that one file by additions only.
