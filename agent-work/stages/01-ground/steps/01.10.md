## Goal

Gate G12 is answered: whether GitHub accepts, from this machine, a push that changes a file under
`.github/workflows/`. The answer is in your report. Nothing is left behind: no branch here, no
branch on GitHub, no file changed.

## Read first

- `../stage.md` (the stage's file, beside `steps/`): the row G12 of the gate table.
- `../../../decisions.md`: rows D20 and D24. D24 is what allows this step to push at all. If
  D24 is still marked `planner (unconfirmed)`, report BLOCKED and do nothing.

## Work

You work in the parent worktree and change no file in it. The probe commit is built with git's
plumbing, on top of `origin/main`, so it carries nothing of this task, and it is pushed straight
to a scratch branch that no worktree has checked out.

1. Run, from the parent worktree, exactly:

   ```
   git fetch origin main
   base=$(git rev-parse origin/main)
   idx=$(mktemp -u)
   blob=$( (git show "$base:.github/workflows/pages-deploy.yml"; echo '# push probe') | git hash-object -w --stdin)
   GIT_INDEX_FILE=$idx git read-tree "$base"
   GIT_INDEX_FILE=$idx git update-index --cacheinfo 100644,"$blob",.github/workflows/pages-deploy.yml
   tree=$(GIT_INDEX_FILE=$idx git write-tree)
   commit=$(git commit-tree "$tree" -p "$base" -m "Probe: a push that changes a workflow file")
   rm -f "$idx"
   git diff --stat "$base" "$commit"
   ```

   The last command must print one file changed, one insertion. If it prints anything else,
   stop and report BLOCKED with the output.
2. Push it and keep the output:
   `git push origin "$commit:refs/heads/bernard/upgrade-protocol-workflow-push-probe" 2>&1 | redact`.
   A workflow that runs on tags only is not started by this push
   (`.github/workflows/pages-deploy.yml:13-18`, `.github/workflows/docker-publish.yml:17-21`).
3. If the push was accepted, delete the scratch branch at once:
   `git push origin --delete bernard/upgrade-protocol-workflow-push-probe 2>&1 | redact`.
   If it was refused, do not try another way in: a refusal is the answer.
4. Prove nothing is left: `git ls-remote origin 'refs/heads/bernard/upgrade-protocol-workflow-push-probe'`
   prints nothing, and `git status --short` in the parent worktree prints what it printed before
   you began.
5. File the report FIRST, then run the exit check. `FINDINGS` must hold these lines, each at the
   start of a line:
   - `G12: holds` when the push was accepted, or `G12: fails` when GitHub refused it
   - `PUSH: ` followed by the decisive line of the push's output, as printed
   - `LEFT BEHIND: none`, or what is left and why you could not remove it

## Done when

`checks/01.10.sh` proves the report holds the three lines with `G12` as `holds` or `fails`, and
asks GitHub itself that the scratch branch does not exist. It cannot prove the verdict matches
what GitHub said: the orchestrator reads the `PUSH:` line.
