## Goal

`probes/README.md` exists and tells a person what the folder is. The step is trivial on purpose:
it proves that a subagent of this model follows a brief, commits on its branch and files a report.

## Read first

nothing

## Work

1. Run `yarn install --immutable`.
2. Write `probes/README.md`, at most 15 lines, for a person and not for an agent. It says: the
   folder holds one-off scripts that put questions to the Midnight preprod indexer, to Node and
   to an EVM node, before the explorer's backend was designed around the answers. Each script's
   answers are in `probes/findings/`. A script is run with plain `node` and takes the indexer URL
   from the environment variable `MIDNIGHT_PREPROD_INDEXER_URL`. The folder is removed before the
   work is merged. Do not point the reader at any agent file or at `agent-work/`.
3. Run `yarn format`, then `yarn lint` and `yarn format:check`. Commit.

## Done when

`checks/01.1.sh` proves the file exists, names the variable and the findings folder, stays within
15 lines, mentions no agent file and passes the format check. It cannot prove the text reads well:
the orchestrator reads it.
