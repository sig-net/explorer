## Goal

`agent-work/probes/README.md` exists in your worktree and says what the folder is. The step is
trivial on purpose: it proves that a subagent of this model follows a brief, commits on its
branch and files a report.

## Read first

nothing

## Work

1. Write `agent-work/probes/README.md` (the path is relative to the root of your worktree), at
   most 15 lines. It says: the folder holds one-off scripts that put questions to the Midnight
   preprod indexer, to Node and to an EVM node, and the design of the explorer's backend rests
   on the answers. Each script's answers are in `agent-work/probes/findings/`. A script is run
   with plain `node` from the repository root and takes the indexer URL from the environment
   variable `MIDNIGHT_PREPROD_INDEXER_URL`. The folder goes when `agent-work/` goes.
2. Commit.

## Done when

`checks/01.1.sh` proves the file exists, names the variable and the findings folder and stays
within 15 lines. It cannot prove the text reads well: the orchestrator reads it.
